Docker Concepts Learned

  1. Docker Image: A lightweight blueprint used to create Docker containers.
  2. Docker Container: A running instance of a Docker image that contains the application.
  3. Dockerfile: A text file containing instructions to build a Docker image.
  4. Nginx: A lightweight web server used to serve static websites efficiently.
  5. Port Mapping: Connects a host machine port to a container port so the application is accessible.
